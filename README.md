# Майстерня Мирослава

Особистий сайт українською про навчання з Raspberry Pi та Freenove: фото, історія про роботів Arduino, десять покрокових місій і щоденник відкриттів.

## Сайт

GitHub Pages: https://myrozu.github.io/myro-pi/

Статичні файли розміщено в корені репозиторію; головна сторінка — `index.html`. Збірка та встановлення залежностей не потрібні. Усі посилання на ресурси відносні, тому сайт працює в підкаталозі `/myro-pi/`.

## Локальний перегляд

```sh
python3 -m http.server 8765
```

Відкрити http://localhost:8765 .

## Публікація

Workflow `.github/workflows/pages.yml` публікує корінь репозиторію через GitHub Actions після змін у гілці `main`. У Settings → Pages джерелом має бути GitHub Actions. Workflow також можна запустити вручну.

## Дані та навчання

Прогрес і нотатки зберігаються лише у браузері (localStorage). JSON-експорт та імпорт допомагають переносити їх між браузерами. Сайт не підключається до Raspberry Pi і не керує GPIO. Нова адреса GitHub Pages має окреме браузерне сховище: для перенесення записів з OpenAI Sites потрібні експорт на старій адресі та імпорт на новій.

Дорослий перевіряє схеми перед увімкненням живлення. Базовий маршрут використовує Python + gpiozero + lgpio. Перед уроками ADC необхідно підготувати I²C на Raspberry Pi.
